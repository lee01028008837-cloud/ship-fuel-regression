# 선박 속도에 따른 주기관 연료소비량의 선형 및 비선형 회귀분석

## 1. 프로젝트 소개

본 프로젝트는 공개된 선박 데이터를 이용하여 선박 속도(Speed)와 주기관 연료소비량(fuelcons)의 관계를 분석하는 프로그램이다.

선형회귀와 2차 다항회귀를 각각 수행하고, 두 모델의 성능을 R², RMSE, MAE를 이용하여 비교한다.

또한 사용자가 선박 속도를 입력하면 두 회귀모델을 이용하여 예상 연료소비량을 계산한다.

---

## 2. 사용 데이터

- 데이터 파일: tanker.csv
- 데이터 개수: 202개
- 입력 변수: Speed
- 출력 변수: fuelcons

### 주요 변수

| 변수 | 설명 |
|---|---|
| Speed | 선박 속도 |
| Power | 기관 출력 관련 변수 |
| Load | 부하 |
| Engines | 기관 수 |
| Propellers | 프로펠러 수 |
| dSpeed | 속도 관련 변수 |
| fuelcons | 연료소비량 |

본 프로젝트에서는 선박 속도(Speed)를 독립변수로 사용하고 연료소비량(fuelcons)을 종속변수로 사용하였다.

---

## 3. 분석 방법

### 3.1 선형회귀

선박 속도와 연료소비량의 관계를 직선으로 표현한다.

선형회귀식은 다음과 같은 형태이다.

y = b0 + b1x

여기서 x는 선박 속도이고 y는 연료소비량이다.

### 3.2 비선형회귀

선형 관계만으로 설명하기 어려운 관계를 표현하기 위해 2차 다항회귀를 사용하였다.

식은 다음과 같은 형태이다.

y = b0 + b1x + b2x²

---

## 4. 데이터 분할

전체 202개의 데이터를 학습 데이터와 테스트 데이터로 나누었다.

- 학습 데이터: 161개
- 테스트 데이터: 41개
- 테스트 데이터 비율: 20%

학습 데이터로 회귀모델을 학습하고 테스트 데이터로 모델의 예측 성능을 평가하였다.

---

## 5. 평가 방법

모델의 성능을 다음 세 가지 지표로 평가하였다.

### R²

모델이 종속변수의 변동을 얼마나 설명하는지를 나타내는 지표이다.

값이 1에 가까울수록 설명력이 높다.

### RMSE

예측값과 실제값의 차이를 제곱한 뒤 평균하여 제곱근을 취한 값이다.

값이 작을수록 예측 오차가 작다.

### MAE

예측값과 실제값의 차이의 절댓값을 평균한 값이다.

값이 작을수록 예측 오차가 작다.

---

## 6. 분석 결과

### 선형회귀

- R²: 0.93099
- RMSE: 4.97502
- MAE: 4.58204

### 2차 다항회귀

- R²: 0.97962
- RMSE: 2.70359
- MAE: 2.14097

2차 다항회귀는 이번 테스트 데이터에서 선형회귀보다 높은 R²와 낮은 RMSE 및 MAE를 나타냈다.

따라서 이번 데이터에서는 선박 속도와 연료소비량의 관계를 직선보다 2차 곡선 형태로 표현했을 때 테스트 데이터의 예측 오차가 더 작게 나타났다.

## 7. 예측 기능

사용자가 선박 속도를 입력하면 선형회귀와 2차 다항회귀 모델을 이용하여 예상 연료소비량을 출력한다.

예를 들어 선박 속도를 15 knot로 입력했을 때:

- 비선형회귀 예측값: 239.37 g/s

로 계산되었다.
